# ReeFood - Food Sharing & Surplus Reduction Platform

**ReeFood** is a community-driven food sharing web application that helps reduce food waste by connecting donors with individuals or organizations in need. The platform allows users to donate surplus food, browse available food items, and request pickups — all through an easy-to-use, responsive interface.

---

## Features

- **User Authentication** – Secure login/logout using email and password
- **Food Donation Form** – Add food items with name, image, quantity, pickup location, expiry date/time, and notes
- **Available Foods Section** – View food listings with expiration countdown and availability status
- **Search & Sort** – Easily find food by name and sort by expiry date
- **Detailed View** – View complete information of a food item, including donor details
- **Responsive Design** – Works on desktops, tablets, and mobile devices
- **Real-time Updates** – Automatically updates food status (e.g., "available", "expired")

---

## Tech Stack

- **Frontend:** React.js, Tailwind CSS, React Router, React Icons  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (via Mongoose)  
- **Authentication:** Firebase Auth (optional)  
- **Hosting:** Vercel (Frontend), Render or Heroku (Backend)
